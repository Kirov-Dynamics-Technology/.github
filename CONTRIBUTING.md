# Contributing to Kirov Dynamics Technology

Welcome, and thank you for your interest in contributing to Kirov Dynamics Technology! We are a proudly South African tech company building AI, security, and infrastructure solutions.

This document serves as the project-wide contribution guide for all repositories in the Kirov-Dynamics-Technology organization.

## 🤝 Team and Credit

At Kirov Dynamics, we believe in shared credit and open collaboration. We acknowledge the contributions of all our team members across our repositories. 

Each repository typically maintains a list of key contributors and their roles. We format our team recognition as follows:
- [@GitHubLogin](https://github.com/GitHubLogin) — Role (e.g., Lead Developer, AI Engineer, Security Analyst)

Credit is distributed based on real commits, and we encourage recognizing every individual who helps move our projects forward.

## 🚀 How to Contribute

We welcome contributions of all kinds—from code to documentation, bug reports to feature requests.

1. **Find an Issue**: Look for open issues labeled `good first issue` or `help wanted` in any of our repositories.
2. **Fork and Branch**: Fork the repository and create a new branch for your feature or bug fix.
3. **Commit Standards**: We follow Semantic Commit conventions:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `chore:` for maintenance tasks
4. **Pull Requests**: Submit a PR to the main repository. Ensure your code passes all automated CI/CD checks and Trivy security scans. A review is required before merging.

## 🔒 Security

We maintain a strict **Zero-Trust Security Policy**. If you discover a security vulnerability, please do NOT open a public issue. Instead, refer to our `SECURITY.md` for instructions on how to privately report it.

## ⚖️ Code of Conduct

All contributors and community members are expected to adhere to our Code of Conduct. Please treat everyone with respect and professionalism.
