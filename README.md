# Kirov Dynamics Enterprise Community Profile
# Global Community Health Files — Raphasha27 GitHub Organization

This repository contains the global community health files that automatically
apply to all Raphasha27 repositories across the ecosystem.

## 📁 What's Included

| File | Purpose |
|:---|:---|
| `.github/ISSUE_TEMPLATE/bug_report.md` | Standardized bug reporting template |
| `.github/ISSUE_TEMPLATE/feature_request.md` | Feature request and enhancement template |
| `.github/ISSUE_TEMPLATE/security_report.md` | Private security vulnerability reporting |
| `.github/PULL_REQUEST_TEMPLATE.md` | Unified PR review checklist |

## 🏛️ Governance Standards

All repositories under `Raphasha27` adhere to:
- **Zero-Trust Security Policy** via `SECURITY.md`
- **Code of Conduct** via `CODE_OF_CONDUCT.md`
- **Semantic Commit** conventions (feat:, fix:, chore:, docs:)
- **Automated CI/CD** with Trivy security scanning
- **Dependabot** weekly dependency audits
